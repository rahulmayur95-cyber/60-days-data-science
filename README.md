# 60-Days Data Science Challenge

## Project Overview: Bank Customer Churn Analysis
* **Domain:** Finance / Banking
* **Dataset:** Bank Customer Churn (`churn.csv`)

### Problem Statement
Customer attrition (churn) directly impacts profitability in the banking sector. The objective of this project is to analyze customer demographic data, credit profiles, account balances, and activity indicators to identify key risk factors driving churn (`Exited` column) and build actionable insights to improve customer retention strategies.
